# Wedge

**Wedge** is a proposed open-source, approximately 2 km regional weather model focused on cold-air damming (CAD), often called the wedge, in the Carolinas and Mid-Atlantic.

The project is at the design stage. There is no model code or operational forecast service here yet. Start with the [design document](DESIGN.md) for the problem, scope, evidence, and open questions.

We are looking for atmospheric modelers, forecasters familiar with CAD, and engineers with experience running numerical weather prediction systems. The first technical target is a reproducible hindcast of a historical CAD event, evaluated against observations and the original NAM output.
